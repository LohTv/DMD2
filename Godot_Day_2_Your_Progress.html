How to use the code blocks without creating new errors

  1. Find the named function in checkpoint_map.gd.
  2. If a block says replace function, replace its complete old body, including the func line. Stop before the next top-level func. Do not append another function with the same name.
  3. If it says add function, add it at the left margin, outside every other function. Add new variables near the existing variables, not inside _ready().
  4. Complete every code change in the current step before running it. A function may appear below its caller, but it must exist.
  5. Save the script and scene, then run that step’s checkpoint. If it fails, fix that step before adding the next one.

Some functions, especially _ready(), _process() and update_display(), are replaced again in a later step as features are added. The later version includes the earlier changes. This avoids relying on unfinished functions, which caused your previous “function not found” errors.

Scene-node names are case-sensitive. Keep the existing children directly under Main unless this guide explicitly creates a new parent. In particular, keep $Options, $Status2 and $Connections at their current paths.

func build_route_curves() -> void:
	route_curves.clear()
	for index in range(routes.size()):
		var route: Dictionary = routes[index]
		var curve: Curve2D
		if route.mode == "walk":
			curve = Curve2D.new()
			curve.add_point(Data.STOPS[route.from].pos)
			curve.add_point(Data.STOPS[route.to].pos)
		else:
			var path = get_node_or_null("Routes/R%d" % index) as Path2D
			if path == null or path.curve == null or path.curve.point_count < 2:
				continue
			curve = path.curve.duplicate() as Curve2D
			curve.set_point_position(0, Data.STOPS[route.from].pos)
			curve.set_point_position(curve.point_count - 1, Data.STOPS[route.to].pos)
		route_curves[index] = curve
