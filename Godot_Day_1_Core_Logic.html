GODOT 4.4.1 · DAY 1 · LEARNING VERSION

Build the logic first

A small route game with connected stops, a clock, a budget and journey choices. Build this before worrying about the finished map.

The timetable, fares, eight stop positions and destination match your existing Day 1 prototype. The background is empty and the connections are straight. Only short, necessary text remains: the time, tokens, current state and travel choices.

There is no instruction overlay, Pause, Restart, Help or Show All button. To start another practice run, stop the game with F8 and run it again with F5. Clicking your current stop clears a destination filter; while waiting, it cancels your booking for free.

Choose a route → wait for departure → pay once → move → arrive → choose again.

This is a separate practice project. Your existing prototype and both original day guides are unchanged. These AI-assisted examples are for learning; use only materials your centre permits during the exam.

Keep indentation consistent. A function body is indented once; the body of an if inside it is indented again. Functions at the top level all begin at the left edge. A function can call one written later in the same file, as long as that function exists.

Two different numbers are easy to confuse: a stop ID identifies a place; a route ID identifies a journey between two places. For example, stop 4 is the destination gate, while route 4 is the first train journey.

MAP_ORIGIN places the graph inside the window. A stop at (70, 410) is drawn at (25 + 70, 126 + 410), which is (95, 536). The stored stop positions are unchanged from your previous prototype.

_draw() contains drawing commands. Lines are drawn first so the stops and the gold marker stay visible on top. The same walking connection exists in both directions in the data, but is drawn only once.

_unhandled_input() receives clicks that a UI control has not already used. It converts the event position to Main’s local coordinates and compares it with MAP_ORIGIN + stop.pos. Drawing and clicking therefore use the same coordinates. The 24-pixel click radius is a little larger than the symbol to make it easier to hit.

6. Give the game a memory

Enter the declarations below at the top of main.gd. The remaining sections contain all the functions to add to that same file. Do not create a new script for each function.

extends Node2D

const MAP_ORIGIN = Vector2(25, 126)
const START_TIME = 480.0
const DEADLINE = 570.0
const GOAL = 4
const IDLE_SPEED = 0.12
const TRAVEL_SPEED = 4.0

var state = State.READY
var game_time = START_TIME
var tokens = 10
var current_stop = 0
var selected_stop = -1
var active_route = -1

game_time is the actual clock value, tokens is the budget, and current_stop is the place the player has reached. Labels only show those values; never read the displayed clock text to decide how the game behaves.

selected_stop is a destination filter. active_route is the booked journey. The value -1 means “none selected”. Do not use -1 to read the routes array: in GDScript that would read its last item.

READY
Choose an option→WAITING
Keep your tokens→TRAVELLING
Pay once; move→READY or FINISHED

enum State gives readable names to four values. A single state prevents contradictions such as choosing another route while travelling. Walking can move straight from READY to TRAVELLING because it departs now. Cancelling a wait returns to READY.

READY is not paused. A minute spent thinking in real life uses 7.2 minutes on the game clock. There is no instructions screen holding the clock at the beginning in this version.

7. Work out the next departure

Add these two helpers to main.gd:

func time_text(minutes: float) -> String:
	var whole_minutes = floori(minutes + 0.000001)
	return "%02d:%02d" % [whole_minutes / 60, whole_minutes % 60]


func next_departure(route: Dictionary, at_time: float = -1.0) -> float:
	var now = game_time if at_time < 0.0 else at_time
	if route.mode == "walk":
		return now
	# Round UP to the next scheduled service; exactly on time is still allowed.
	var services_passed = maxi(0, ceili((now - route.first) / route.interval))
	return route.first + services_passed * route.interval

time_text() turns minutes into a string for the screen. Division gives hours; % 60 gives the remaining minutes. %02d pads each part with a leading zero. The stored clock stays a float, so it can advance by fractions of a minute.

next_departure() answers a question; it does not advance time or buy a ticket. It uses the current clock unless a future time is supplied. That second use lets the connection preview work out what you could catch after arriving somewhere else.

departure = first + number_of_intervals × interval

To find the number of intervals, divide the time since the first departure by the interval, round up with ceili(), then keep it at least zero with maxi().

Time nowFirst train: 490, interval: 30Next departure
08:05 / 485ceil((485 − 490) / 30) = 0490 / 08:10
08:10 exactly / 490ceil(0 / 30) = 0490 / 08:10
08:11 / 491ceil(1 / 30) = 1520 / 08:40
08:41 / 521ceil(31 / 30) = 2550 / 09:10

Why round up? At 08:11, the 08:10 departure has already gone. Rounding down would offer a journey in the past.

The screen shows whole minutes, but the timetable uses the precise clock. A displayed 08:10 can mean 08:10 plus a few seconds. If a service has just departed, the next option can already show 08:40. This is the same rule as the original prototype.

8. Turn routes into choices

Add these functions:

func select_stop(stop_index: int) -> void:
	if stop_index < 0 or stop_index >= Data.STOPS.size():
		return
	if state == State.WAITING and stop_index == current_stop:
		cancel_wait()
		return
	if state != State.READY:
		return
	# -1 means show all outgoing routes, with no destination filter.
	selected_stop = -1 if stop_index == current_stop else stop_index
	rebuild_options()
	update_display()


func available_routes() -> Array[int]:
	var result: Array[int] = []
	if state != State.READY:
		return result
	for index in range(routes.size()):
		var route: Dictionary = routes[index]
		if route.from != current_stop:
			continue
		if selected_stop != -1 and route.to != selected_stop:
			continue
		result.append(index)
	return result


func rebuild_options() -> void:
	for child in options.get_children():
		options.remove_child(child)
		child.queue_free()
	for index in available_routes():
		var button = Button.new()
		button.custom_minimum_size = Vector2(320, 70)
		button.focus_mode = Control.FOCUS_NONE
		button.set_meta("route_index", index)
		button.pressed.connect(choose_route.bind(index))
		options.add_child(button)

available_routes() returns route indices. First it rejects routes that do not start at current_stop. If a destination is selected, it also rejects routes going somewhere else. From stop 0, the unfiltered choices are the horse to stop 1 and the walk to stop 5.

select_stop() changes the filter. Clicking your own stop removes it; clicking a different stop shows direct choices to that stop. Choosing a stop is not buying a journey. During WAITING, clicking your current stop cancels the booking instead.

rebuild_options() removes the previous buttons and creates one for every available route. remove_child() detaches the old control immediately, and queue_free() safely deletes it at the end of the frame.

button.pressed.connect(choose_route.bind(index)) means “when this button is pressed, call choose_route with this route’s index”. bind(index) remembers which journey belongs to this button. Calling choose_route(index) directly here would book the journey while creating the button.

The route index is also stored as metadata so update_display() can refresh that button’s price and times. Rebuild the button list when the state or selected stop changes; update its text while the clock runs. Recreating every button every frame could interrupt a click.

Why does clicking stop 7 from stop 0 not offer a direct train? Which walking route gets you to a place where train options become available?

9. Book a journey and pay only when it departs

func choose_route(route_index: int) -> void:
	if state != State.READY or route_index < 0 or route_index >= routes.size():
		return
	var route: Dictionary = routes[route_index]
	if route.from != current_stop or route.cost > tokens:
		return
	active_route = route_index
	departure_time = next_departure(route)
	arrival_time = departure_time + route.duration
	state = State.WAITING
	if departure_time <= game_time:
		board()
	rebuild_options()
	update_display()


func board() -> void:
	# This guard prevents a second call from charging the fare again.
	if state != State.WAITING:
		return
	tokens -= int(routes[active_route].cost)
	state = State.TRAVELLING


func cancel_wait() -> void:
	if state != State.WAITING:
		return
	state = State.READY
	active_route = -1
	selected_stop = -1
	rebuild_options()
	update_display()

choose_route() first checks that the player is READY, the route starts where they are and they can afford it. These checks still matter even if the UI disables expensive buttons: the function itself should reject an invalid journey.

A valid choice stores the route index, calculates a departure and sets arrival_time = departure_time + duration. The state becomes WAITING. If departure is now, it calls board() immediately.

Reserving a future departure does not deduct money. board() is the only place that pays the fare. It changes the state to TRAVELLING, which prevents another boarding charge for the same booking. If a paid service departs immediately, choose_route() calls board() at once, so that click also causes the payment.

cancel_wait() clears the booking and returns to READY. No refund code is needed because the player has not paid yet. The clock does not go backwards: the time already spent waiting is still gone.

Choice reserves the journey. Boarding pays for it. Arrival changes your stop.

10. Let time trigger boarding and arrival

func tick_clock(delta: float) -> void:
	if state == State.FINISHED:
		return
	var speed = IDLE_SPEED if state == State.READY else TRAVEL_SPEED
	var next_time = game_time + delta * speed
	if state == State.WAITING:
		game_time = minf(next_time, departure_time)
		if game_time >= departure_time:
			board()
	elif state == State.TRAVELLING:
		game_time = minf(next_time, arrival_time)
		if game_time >= arrival_time:
			arrive()
	else:
		game_time = next_time


func arrive() -> void:
	if state != State.TRAVELLING:
		return
	current_stop = int(routes[active_route].to)
	active_route = -1
	selected_stop = -1
	state = State.FINISHED if current_stop == GOAL else State.READY
	rebuild_options()

delta is the number of real seconds since the previous frame. Multiplying it by a rate gives the amount of game minutes to add. At 60 frames per second, delta is roughly 1/60; it is not always exactly that.

At the active rate of 4.0, one real second advances the clock by four game minutes. The 24-minute first train journey therefore takes about six real seconds to animate. The free five-minute walk takes about 1.25 seconds.

The clock is clamped with minf() to the next event. While waiting, it stops at the departure and calls board(). While travelling, it stops at the arrival and calls arrive(). Even a slow frame cannot jump past the event without processing it.

This simple controller uses one transition per frame and discards any leftover portion of that frame at a boundary. That is sufficient for this prototype and keeps the code readable. It does not model a full transport simulation.

arrive() updates current_stop to the journey’s destination and clears the old selection. At stop 4 it sets FINISHED. Elsewhere it returns to READY and offers the next choices.

The deadline is checked when you reach stop 4. Arriving by 09:30 succeeds; arriving later gives a late result. The game does not suddenly end elsewhere on the map at 09:30. Reaching stop 7 by train is not the finish: the last walk to stop 4 still matters.

11. Use the clock to move the player

func travel_progress() -> float:
	if state != State.TRAVELLING:
		return 0.0
	return clampf((game_time - departure_time) / (arrival_time - departure_time), 0.0, 1.0)


func player_position() -> Vector2:
	if state != State.TRAVELLING:
		return MAP_ORIGIN + Data.STOPS[current_stop].pos
	var route: Dictionary = routes[active_route]
	var start: Vector2 = Data.STOPS[route.from].pos
	var finish: Vector2 = Data.STOPS[route.to].pos
	return MAP_ORIGIN + start.lerp(finish, travel_progress())

travel_progress() returns a fraction between 0 and 1:

progress = (game_time − departure_time) / (arrival_time − departure_time)

On the first train, departure is 490 and arrival is 514. At 502, progress is (502 − 490) / (514 − 490) = 12 / 24 = 0.5. The train is halfway through its journey.

player_position() uses start.lerp(end, progress) to find a point on the straight line. At progress 0 it returns the start; at 0.5 it returns the midpoint; at 1 it returns the destination. While READY or WAITING it returns the current stop’s position.

The first train’s positions are (95, 460) and (550, 380), so the halfway position is (322.5, 420), before adding the map origin. The first horse travels from (70, 410) to (210, 370), giving (140, 390) halfway.

There is no second independent animation timer. Movement, arrival and the line’s opacity all use the same progress. That prevents the marker reaching the destination before the timetable says it has arrived.

			preview_stop = selected_stop
			preview_time = minf(preview_time, leaves + route.duration)
	if state == State.WAITING or state == State.TRAVELLING:
		preview_stop = int(routes[active_route].to)
		preview_time = arrival_time
	connections_label.text = connection_note(preview_stop, preview_time) if preview_stop >= 0 else ""
	queue_redraw()


func connection_note(stop_index: int, at_time: float) -> String:
	if stop_index == GOAL:
		return ""
	var lines: Array[String] = ["Next from %d (after %s):" % [stop_index, time_text(at_time)]]
	for route in routes:
		if route.from != stop_index:
			continue
		var leaves = next_departure(route, at_time)
		lines.append("%s > %d: %s - %s, %d tokens" % [route.mode.capitalize(), route.to, time_text(leaves), time_text(leaves + route.duration), route.cost])
	return "\n".join(lines)

update_display() writes the clock, remaining tokens and short status. It refreshes each route button’s departure, arrival and cost, and disables journeys that cost more tokens than the player has.

connection_note() is the short preview below the options. Select a reachable destination, or book a route, to see it. It looks forward from that destination’s expected arrival time and lists its direct outgoing journeys. It describes choices; it does not book them or change the clock.

For example, the first train reaches stop 6 at 08:34. The next train from there leaves at 08:37. If you instead reach road stop 2 at 08:40, the four-minute walk reaches stop 6 at 08:44, so that train has already gone and the next is 09:07.

At road stop 2, the preview shows the walk to station 6. It does not also calculate the train after that walk: select or book that walking leg to preview the train. This is a shorter preview than the original guide’s. It is not a path-finding algorithm that calculates the best whole journey.

queue_redraw() requests a fresh drawing. Changing game_time alone would update the number in memory, but would not necessarily redraw a custom marker on screen.

18. What to remember, rather than memorising every line

  1. Data: a stop has a position; a route has two endpoints, a timetable, a duration and a cost.
  2. Selection: offer routes that start at the current stop; optionally filter by the clicked destination.
  3. Booking: calculate the next departure and arrival; enter WAITING.
  4. Boarding: deduct the fare once; enter TRAVELLING.
  5. Movement: convert elapsed journey time into a fraction; interpolate between the endpoints.
  6. Arrival: change the current stop; either rebuild the choices or finish.
  7. Display: read the stored state and show it. The screen does not own the game rules.

enum State { READY, WAITING, TRAVELLING, FINISHED }
const MAP_ORIGIN = Vector2(25, 126)
const START_TIME = 480.0
const DEADLINE = 570.0
const GOAL = 4
const IDLE_SPEED = 0.12
const TRAVEL_SPEED = 4.0

var state = State.READY
var game_time = START_TIME
var tokens = 10
var current_stop = 0
var selected_stop = -1
var active_route = -1
var departure_time = 0.0
var arrival_time = 0.0
var routes: Array[Dictionary] = Data.make_routes()

@onready var clock_label: Label = $Clock
@onready var money_label: Label = $Money
@onready var status_label: Label = $Status
@onready var options: VBoxContainer = $Options
@onready var connections_label: Label = $Connections


func _ready() -> void:
	rebuild_options()
	update_display()


func time_text(minutes: float) -> String:
	var whole_minutes = floori(minutes + 0.000001)
	return "%02d:%02d" % [whole_minutes / 60, whole_minutes % 60]


func next_departure(route: Dictionary, at_time: float = -1.0) -> float:
	var now = game_time if at_time < 0.0 else at_time
	if route.mode == "walk":
		return now
	# Round UP to the next scheduled service; exactly on time is still allowed.
	var services_passed = maxi(0, ceili((now - route.first) / route.interval))
	return route.first + services_passed * route.interval


func select_stop(stop_index: int) -> void:
	if stop_index < 0 or stop_index >= Data.STOPS.size():
		return
	if state == State.WAITING and stop_index == current_stop:
		cancel_wait()
		return
	if state != State.READY:
		return
	# -1 means show all outgoing routes, with no destination filter.
	selected_stop = -1 if stop_index == current_stop else stop_index
	rebuild_options()
	update_display()


func available_routes() -> Array[int]:
	var result: Array[int] = []
	if state != State.READY:
		return result
	for index in range(routes.size()):
		var route: Dictionary = routes[index]
		if route.from != current_stop:
			continue
		if selected_stop != -1 and route.to != selected_stop:
			continue
		result.append(index)
	return result


func rebuild_options() -> void:
	for child in options.get_children():
		options.remove_child(child)
		child.queue_free()
	for index in available_routes():
		var button = Button.new()
		button.custom_minimum_size = Vector2(320, 70)
		button.focus_mode = Control.FOCUS_NONE
		button.set_meta("route_index", index)
		button.pressed.connect(choose_route.bind(index))
		options.add_child(button)


func choose_route(route_index: int) -> void:
	if state != State.READY or route_index < 0 or route_index >= routes.size():
		return
	var route: Dictionary = routes[route_index]
	if route.from != current_stop or route.cost > tokens:
		return
	active_route = route_index
	departure_time = next_departure(route)
	arrival_time = departure_time + route.duration
	state = State.WAITING
	if departure_time <= game_time:
		board()
	rebuild_options()
	update_display()


func board() -> void:
	# This guard prevents a second call from charging the fare again.
	if state != State.WAITING:
		return
	tokens -= int(routes[active_route].cost)
	state = State.TRAVELLING


func cancel_wait() -> void:
	if state != State.WAITING:
		return
	state = State.READY
	active_route = -1
	selected_stop = -1
	rebuild_options()
	update_display()


func tick_clock(delta: float) -> void:
	if state == State.FINISHED:
		return
	var speed = IDLE_SPEED if state == State.READY else TRAVEL_SPEED
	var next_time = game_time + delta * speed
	if state == State.WAITING:
		game_time = minf(next_time, departure_time)
		if game_time >= departure_time:
			board()
	elif state == State.TRAVELLING:
		game_time = minf(next_time, arrival_time)
		if game_time >= arrival_time:
			arrive()
	else:
		game_time = next_time


func arrive() -> void:
	if state != State.TRAVELLING:
		return
	current_stop = int(routes[active_route].to)
	active_route = -1
	selected_stop = -1
	state = State.FINISHED if current_stop == GOAL else State.READY
	rebuild_options()


func _process(delta: float) -> void:
	tick_clock(delta)
	update_display()


func travel_progress() -> float:
	if state != State.TRAVELLING:
		return 0.0
	return clampf((game_time - departure_time) / (arrival_time - departure_time), 0.0, 1.0)


func player_position() -> Vector2:
	if state != State.TRAVELLING:
		return MAP_ORIGIN + Data.STOPS[current_stop].pos
	var route: Dictionary = routes[active_route]
	var start: Vector2 = Data.STOPS[route.from].pos
	var finish: Vector2 = Data.STOPS[route.to].pos
	return MAP_ORIGIN + start.lerp(finish, travel_progress())


func update_display() -> void:
	clock_label.text = time_text(game_time)
	money_label.text = "%d tokens" % tokens
	status_label.text = "Stop %d | Goal %d by %s" % [current_stop, GOAL, time_text(DEADLINE)]
	if state == State.READY and selected_stop != -1:
		status_label.text += " | To %d" % selected_stop
		if available_routes().is_empty():
			status_label.text += " | No direct route"
	elif state == State.WAITING:
		status_label.text = "Waiting until %s | Click stop %d to cancel" % [time_text(departure_time), current_stop]
	elif state == State.TRAVELLING:
		status_label.text = "%s to %d | Arrive %s" % [routes[active_route].mode.capitalize(), routes[active_route].to, time_text(arrival_time)]
	elif state == State.FINISHED:
		status_label.text = "Arrived on time" if game_time <= DEADLINE else "Arrived too late"

	var preview_stop = -1
	var preview_time = INF
	for button in options.get_children():
		var route: Dictionary = routes[int(button.get_meta("route_index"))]
		var leaves = next_departure(route)
		button.text = "%s > %d | %d tokens\nDep %s | Arr %s" % [route.mode.capitalize(), route.to, route.cost, time_text(leaves), time_text(leaves + route.duration)]
		button.disabled = route.cost > tokens
		if button.disabled:
			button.text += "\nToo expensive"
		if selected_stop != -1:
			preview_stop = selected_stop
			preview_time = minf(preview_time, leaves + route.duration)
	if state == State.WAITING or state == State.TRAVELLING:
		preview_stop = int(routes[active_route].to)
		preview_time = arrival_time
	connections_label.text = connection_note(preview_stop, preview_time) if preview_stop >= 0 else ""
	queue_redraw()
